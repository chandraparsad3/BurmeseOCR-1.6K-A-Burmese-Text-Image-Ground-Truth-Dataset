
# BurmeseOCR-1.6K Dataset

BurmeseOCR-1.6K is a dataset containing **1,574 Burmese text images paired with ground-truth transcriptions**, developed to support academic research in Optical Character Recognition (OCR) and low-resource language processing.

## Dataset Details

- **Samples:** 1,574 image–text pairs
- **Image format:** PNG
- **Annotation files:** CSV and Excel
- **Median image dimensions:** 463 × 68 pixels
- **Text length:** 1–180 Unicode code points
- **Data integrity:** All 1,574 referenced images were readable during the dataset audit.
